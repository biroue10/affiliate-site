## OurDream en bref

La plateforme propose notamment :

- chat texte ;
- personnages personnalisés ;
- génération d'images ;
- génération de vidéos ;
- voix ;
- appels vocaux ;
- interactions de groupe ;
- système de crédits appelé Dreamcoins.

Cette diversité constitue son principal intérêt, mais rend également son modèle tarifaire plus complexe.

L'abonnement mensuel comprend notamment :

- 1 000 Dreamcoins immédiatement ;

## Que sont les Dreamcoins ?

Les Dreamcoins constituent la monnaie interne d'OurDream.

Ils permettent notamment d'utiliser différentes fonctions :

- génération d'images ;
- vidéos ;
- appels vocaux ;
- voix ;
- création et personnalisation ;
- modèles conversationnels avancés.

## Combien coûte le chat ?

Le guide officiel indique actuellement :

- chat standard abonné : 0 Dreamcoin ;
- utilisateur gratuit : 1 Dreamcoin par message ;
- certains modèles avancés : 1 Dreamcoin par réponse.

Cela signifie qu'un abonné principalement intéressé par la conversation standard n'a pas nécessairement le même besoin en crédits qu'un utilisateur produisant de nombreux médias.

## Combien coûtent les images ?

La documentation indique notamment :

- génération standard : 10 Dreamcoins pour deux images ;
- certaines générations dans le chat : 5 Dreamcoins par image ;
- amélioration ou édition : coût supplémentaire selon le modèle.

Les montants sont susceptibles d'évoluer et doivent donc être vérifiés directement avant achat.

## Et les vidéos ?

La vidéo est nettement plus coûteuse en crédits.

Le guide officiel indique par exemple un coût de base de :

**100 Dreamcoins pour cinq secondes de vidéo standard.**

Une utilisation intensive de la vidéo peut donc consommer rapidement l'allocation mensuelle.

## Les appels vocaux

Les appels vocaux sont également facturés en crédits.

La documentation consultée indique :

**50 Dreamcoins par minute.**

C'est un élément important à prendre en compte lorsqu'on compare OurDream avec un service proposant essentiellement du chat.

## OurDream fonctionne-t-il en français ?

Le centre d'aide indique qu'il est possible de demander au personnage de répondre dans une langue autre que l'anglais.

Il peut toutefois être nécessaire de le rappeler pendant quelques messages.

Nous n'en déduisons pas que la qualité du français est systématiquement identique à celle de l'anglais.

## OurDream possède-t-il une application ?

OurDream n'annonce actuellement pas d'application mobile native.

La plateforme explique qu'elle peut être installée comme une Progressive Web App depuis le navigateur afin d'obtenir une expérience proche d'une application.

## Confidentialité et conversations

OurDream affirme dans sa documentation de sécurité ne pas vendre les conversations privées.

La plateforme indique aussi utiliser une combinaison de systèmes automatisés et de revue humaine pour certains contenus signalés ou nécessitant une vérification.

Il faut donc, comme avec tout compagnon IA hébergé en ligne, éviter d'utiliser la conversation comme stockage de données sensibles.

Notre [analyse transversale de la confidentialité des compagnons IA](/guides/ai-girlfriend-confidentialite-securite/) compare également conservation, modération, entraînement et suppression.

## Comment supprimer son compte OurDream ?

La suppression est accessible depuis le profil.

La documentation indique qu'elle entraîne notamment la suppression :

- des personnages ;
- des générations ;
- de l'historique des chats ;
- des Dreamcoins inutilisés ;
- de l'accès au compte.

La suppression est décrite comme définitive.

OurDream annonce généralement un traitement de la demande sous 24 à 48 heures.

## Que se passe-t-il avec l'abonnement ?

Si un compte possédant un abonnement actif est supprimé, OurDream indique que l'abonnement est automatiquement annulé.

Une simple annulation d'abonnement est différente d'une suppression complète du compte.

## À qui OurDream convient-il ?

OurDream semble particulièrement intéressant pour quelqu'un qui souhaite combiner :

- conversation ;
- images ;
- vidéos ;
- voix ;
- appels ;
- personnages personnalisés.

## Son principal défaut

Le système de crédits.

La diversité fonctionnelle est importante, mais elle rend également le coût réel plus difficile à prévoir.

Le nombre de Dreamcoins consommé dépend fortement des fonctions utilisées.

Pour quelqu'un utilisant beaucoup la vidéo ou les appels, la consommation de Dreamcoins devient une partie centrale du coût réel.
